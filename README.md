# 📊 Mobile Phone Pricing Data Analysis

A comprehensive data analysis project focused on understanding the factors that influence mobile phone pricing. The project involves data cleaning, preprocessing, exploratory data analysis (EDA), and visualization techniques to uncover patterns, relationships, and key insights within the dataset.

Using graphical analysis and statistical exploration, the project identifies how various smartphone specifications impact price categories and helps derive meaningful conclusions from the data.

## 🚀 Features

* 🧹 Data cleaning and preprocessing
* 📈 Exploratory Data Analysis (EDA)
* 📊 Graphical visualization of key features
* 🔍 Correlation and trend analysis
* 📱 Investigation of factors affecting mobile phone prices
* 💡 Insight generation through statistical and visual methods

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📂 Dataset

**Mobile Phone Price Prediction Dataset**

Dataset Source:
https://www.kaggle.com/datasets/dewangmoghe/mobile-phone-price-prediction

The dataset contains various smartphone specifications such as:

* RAM
* Internal Memory
* Battery Capacity
* Camera Resolution
* Processor Features
* Display Characteristics
* Connectivity Options
* Price Category

## 🔄 Project Workflow
